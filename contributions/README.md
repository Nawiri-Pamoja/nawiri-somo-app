# Contributions from helpers

Put the files that helpers export from the app here (**Helpers → Export everything**,
file names like `nawiri-contrib-<name>-<date>-<tablet>.txt`).

- On github.com: open this folder → **Add file** → **Upload files** → drag the files in → **Commit changes**.
- Any number of files and sub-folders (for example one folder per visit: `2026-12-boro/`).
- Sending the same tablet's export again is fine: for every entry the newest version wins.
- Recordings made outside the app: `audio/luo/<entry-id>.m4a` (ids are in `review/dholuo-review.csv`).

After every commit the app is rebuilt and published automatically.
The result is in `review/community-report.md` and in the summary of the “Deploy to GitHub Pages” run:
who helped, how much, and **where helpers disagree** (please decide those and correct them in the app).

By exporting, helpers agreed to publish their work under CC BY-SA 4.0 (see `../LICENSE-CONTENT.md`).
